# Skill Motion UI

Скилл для Codex: дизайн из Figma → работающий интерфейс → заданный пользователем флоу → чистая запись и смонтированный шоурилл.

## Статус

Начальная версия с тремя вариантами подачи по пяти видеореференсам: демо фичи, сценарий с акцентами и продуктовый проморолик. Референсы разобраны по метаданным и последовательностям кадров; точные кривые анимации не измерены. Полный цикл записи реального проекта ещё не проверен.

## Установка

Скачайте репозиторий и скопируйте папку `skills/figma-showreel` в `$CODEX_HOME/skills` или `~/.codex/skills`, если переменная не задана. Если такая папка уже существует, сначала сравните версии и сохраните свои изменения.

Скилл использует доступный в среде профильный скилл Figma design-to-code и доступ к нужному макету. Для записи и монтажа нужны соответствующие инструменты: например, браузерная автоматизация и FFmpeg. Они не входят в этот репозиторий и не устанавливаются самим копированием скилла.

## Использование

```text
Используй $figma-showreel.
Figma: [ссылка на экран или набор экранов].
Проект: [путь к проекту или указание создать новый].
Флоу: [действия и ожидаемые результаты по порядку].
Референсы: [примеры желаемого движения и монтажа].
Формат: [размер, длительность, пожелания к титрам и звуку].
```

Результат: код интерфейса, воспроизводимый сценарий, чистая запись и смонтированное видео. Доступность экспорта зависит от инструментов среды; скилл должен явно сообщать о блокерах.

## Состав

- `skills/figma-showreel/SKILL.md` — рабочие инструкции.
- `skills/figma-showreel/agents/openai.yaml` — название и подсказка для вызова.
- `skills/figma-showreel/references/motion-direction.md` — работа с референсами, сценами и движением.

Исходные видеореференсы в репозиторий не включены.

Рабочая ветка: `Skill-motion`.
